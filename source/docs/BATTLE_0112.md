# 0.11.2 法师之手与 DM 续接

法师之手现在支持地图选点生成。点击幽灵手或操作栏的“操控法师之手”选择新位置，确认后移动；“解散法师之手”移除。战斗中施放、操控、解散各消耗动作。范围30尺、持续60秒游戏时间，重施替换旧手，离施法者超过30尺消失。它是法术效果，不占先攻、不阻挡单位，没有生物AC/HP；开门、取物等具体行为仍由DM按规则裁定。探索时间通过游戏时间推进，非现实计时。

DM续接并发请求返回处理中状态，不再误报失败。处理期间停止自动重发；整次模型工具循环共用120秒网络截止时间，单轮最多90秒，失败后30秒冷却。已执行动作保留，不通过清空锁启动重叠模型调用。主对话区显示处理秒数，结束后清除等待提示。

验证使用隔离角色与合成场景：法师之手生成/控制/重施/过期/超距/重启、并发请求只产生一次模型调用、超时后释放续接和聊天状态。另以打包版实际按钮及地图点击验收生成、移动、解散。
