# 0.9.0 战斗重构测试版

## 操作

顶部打开「战斗专页」。中间是放大的地图和动作栏，左右保留角色生命/资源、DM 对话与战斗记录。工作台面板标题、角色卡以及特性/法术详情旁的 ↗ 可打开独立页签，× 关闭；不是外部浏览器。

开启回合制后按先攻行动。点击武器/法术 → 地图上选唯一目标，范围法术选择原点/朝向 → 预览 → 确认执行。预览检查回合、距离、遮挡和资源，不消耗资源。过期预览必须重做。支持的动作确认后，本地执行器依次进行命中/豁免、伤害及状态更新，再通知 DM 续接。可选择自己点击骰子或自动投自己行动的骰子；玩家的受击豁免、机会攻击反应仍保留选择窗口。多个请求严格按队首处理。

旧存档第一次施法需要「确认 / 调整剩余法术位」，按真实余额填写。容量不等于剩余数量，不会把旧角色自动补满。

HP 旁显示临时生命，不叠加，伤害优先扣除；效果按游戏时间到期。地图保留持续区域与专注/时间提示。自由模式点击玩家棋子，再点击地面移动；回合模式检查路径、移动预算和机会攻击。疾走、撤离、结束回合均为独立按钮。连续敌方基础回合是可选项，特殊能力仍交给 DM。

默认地图采用原创纸色、墨线、墙体排线样式，参考 Dungeon Scrawl 的绘图表现，不打包该网站的素材或服务。工作台可切回彩色地图；已有编辑器与 PDF 原图底图保留。

## 已落地的自动规则

- 2014 基础武器攻击：命中、AC、自然1/20、暴击伤害骰、基础额外攻击、装填限制，以及常见状态的优势/劣势抵消。
- 火焰箭、低等级单束魔能爆、酸液飞溅、燃烧之手、魔法飞弹、虚假生命、云雾术、疗伤术、治愈真言的基础模板。
- 范围/双目标伤害共用一次伤害投骰。检查射程、视线、掩体 AC/敏捷豁免；读取角色卡的真实施法和豁免数据。
- 基础动作/附赠动作、原环法术位与附赠施法限制。移动、撤离及基础机会攻击；受伤触发专注，0HP 终止专注，玩家死亡豁免。
- 敌人从绑定的规则条目读取第一项可靠近战攻击；没有资料会停止。也可由 DM 查证后通过 map.token.update 填 attackBonus、damage、reach 和 saves。

这是规则子集，不是完整《博德之门3》或完整 5e 模拟器。升环、弹药库存、战技/偷袭/抗性免疫、特殊怪物能力、护盾术等改变命中结果的反应、兼职施法与子职业例外，需要 DM 查规则手工裁定。魔法飞弹模板目前集中攻击一个目标；多束魔能爆交给 DM。地图 PDF 未校对地形时不能声称视觉上的墙体已经可用于路径判定。复杂情况请在确认前交给 DM，而非期待基础按钮覆盖全部规则。

## AI 接口和提示词

`src/ai-prompts.mjs` 将 AIDM_PROMPTS.md / AIDM_INTEGRATION.md 的有效建议改编为运行时模块：共同约束 + 筹备 / 探索社交 / 战斗模式 + 最新权威场景。按模式裁剪工具；切换状态后重新组装，不包含硬编码模组剧情。

模型原生工具、dm-action JSON 兼容桥（含 ability 战斗动作）、漏调用修复继续保留。单玩家场景中，明确「请掷 1d20+3，DC 15」会直接转成真实骰子请求，不依赖模型第二次回答。假设、建议或怪物属性里的骰式不会自动触发。多玩家歧义仍需明确 actorId，不能猜是哪一个人。

`battle.get / begin / preview / enemy` 供 AI 读取现场与建立交互；UI 通过 submit / resources / reaction / deathSave / utility / endTurn 执行玩家选择。AI 只能叙述成功回执中的结果，不应再次扣相同伤害或资源。未知法术明确走 DM 裁定路径。

两份建议文档仍是设计参考，不是已全部实现的功能声明。流式叙事、完整休息/任务引擎、所有特殊反应与全面规则自动化属于后续扩展。

## 状态与文件

- `saves/battle.json`：动作计划、稳定 actionId、骰子结果、回执、事件和未完成提交的投影。
- `saves/current.json`：包含 battle 状态的战役检查点；`saves/chat.json` 保存对话，`saves/battles/` 保存已结束战斗回放。
- 角色与地图工作副本仍在 AppData；模组、规则书、PDF 和图片仍在 EXE 同级 library。

动作通过同一命令队列串行处理，先写完整投影再更新角色/地图/骰子等旧文件；重启自动补齐已提交投影。同 actionId 或骰子重复点击返回原回执。未完成动作会阻止切换模式或直接改血等冲突操作。投骰结果已提交但 DM 断线时，本地结果保留。

这不是全项目所有旧接口的数据库事务迁移；新动作执行器覆盖的状态有恢复保证。不要在程序运行时由外部工具直接编辑存档 JSON。

## 验证与分发

隔离行为测试覆盖攻击、资源、FIFO、重复提交、重启恢复、共享范围伤害、反应、额外攻击、死亡豁免和骰子文字兼容。桌面点击测试验证目标/范围选择、临时生命、卡片页签、自由移动、敌方回合角色卡及窄窗口；原有31个面板保留渲染冒烟。

发送完整 `SoloTRPG-0.9.0-Windows-x64.zip`，解压后打开最外层 EXE。保留 runtime 和 library，不能只发启动 EXE。升级前关闭程序，替换程序文件并保留自己的 saves、library/data/modules 和 map-images。
