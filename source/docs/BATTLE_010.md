# 0.10.0 角色同步与战斗操作栏

角色卡、地图玩家棋子、战斗状态和发给 DM 的 scene.get 现在共用角色卡派生值。剧情获得物品通过 character.update 写背包，确认穿戴后写装备槽并重算 AC；同一 changeId 重试不重复发放。普通皮甲和盾牌可从本地规则补全属性。兼容 dm.action(action=character) 与 dm-action JSON 围栏，探索和战斗工具白名单均支持。

旧剧情漏写可在战斗页点击「核对剧情装备」：DM 对照现有对话与角色卡，只补明确发生且尚未写入的奖励。若历史对话中没有足够依据，需要进一步说明；程序不会扫描几个词就自动发装备。手工 AC 覆盖值仍尊重角色卡现有设置，装备回执会指出覆盖是否启用。

## 操作

- 地图下方显示角色头像、HP、临时生命/生命上限增益、AC、动作/附赠/反应、移动余量、法术位与技能栏。点头像打开角色卡页签。临时生命与生命上限增益在角色卡 HP 框内整合显示，耗尽或到期时撤销；护盾术等限时 AC 加值通过 effect.add(acBonus) 登记，不作为永久装备。
- 点法术即显示射程；已支持的范围法术立即出现区域预览，鼠标选原点/朝向后确认。点棋子以唯一 ID 选目标，也能查看简表或向 DM 询问。未知法术仍需 DM 查规则裁定，不宣称全部法术已自动化。
- 本地支持的动作结算后可以继续移动、使用剩余动作；点「结束我的回合」才提交整轮结果给 DM，自动读取最新位置、血量、AC、装备与资源。未完成投骰/反应时不能结束；重复点击不跳过下一单位。DM 裁定类请求仍在选择完成后续接。
- 拖动地图/对话间竖线、地图/操作栏间横线、对话/战斗记录间横线调整大小；地图滑条或 Ctrl+滚轮缩放地图，操作栏缩放滑条调整技能栏大小。「专注地图」可隐藏右侧。「定位角色」将玩家棋子移入视野。「重置布局」恢复默认，布局自动保存在本机。
- 回合制下按先攻和行动预算操作；自由模式可直接在地图移动。敌人回合始终保留选中的玩家角色卡与法术信息。

## 验证和边界

测试仅使用隔离角色与存档。覆盖装备授予/穿戴/卸下、重启幂等、AC 多视图一致、临时生命吸收、生命上限与 AC 增益到期、AI 兼容装备指令、结束回合的真实上下文与防重复。桌面事件测试覆盖技能选择、立即范围预览、FIFO 骰子、角色卡页签、鼠标拖动布局、小窗口及自由移动。

自动规则范围仍按 BATTLE_09.md：这是游戏式操作界面与本地基础规则执行器，不是完整博德之门 3 规则实现。模型不遵循工具协议时仍可能需要核对/重试；本地已支持动作的命中、伤害及资源结算不依赖模型口头报值。时间按游戏推进而非现实钟表流逝。

本轮验收：34 项隔离回归、31 个旧面板渲染检查通过；打包版桌面交互通过且页面错误为空。已有 DeepSeek 配置在线隔离实测成功调用 character.update 写入皮甲/盾牌并同步 AC 15，建立两条骰子队列、范围请求和 battle.begin 虚假生命请求。在线模型存在波动，前次施法探针未建立预期请求，复测通过不代表每次必定遵守协议。
