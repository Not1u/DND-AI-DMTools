# 0.11.0 战斗循环修复

## 用户流程

进入回合制会自动打开战斗页，玩家先攻骰完成前不能行动或推进敌方。当前玩家可用动作亮起，点击法术或武器选择地图目标，结算后结束回合。DM 读取权威状态并裁定，基础敌方执行器补齐尚未完成的移动/攻击/结束回合，回到玩家或停在待投骰/反应处。未知攻击资料、遮挡、未支持能力会明确暂停，不虚构命中或数值。

「让 DM 继续敌方」可重试连接；「当前敌方空过」是用户明确裁定当前 NPC 不行动的人工恢复入口。不会跳过玩家或未完成的投骰/行动。默认勾选 DM 自动续接敌方；选择关闭只停止该页面的主动续接，已经提交的结束回合仍会交给 DM。

自由模式下可以自由移动、点击潜行或法术表达意图，再由 DM 判断检定与资源。底部按钮变为「提交探索行动」，把当前位置送给 DM。表达攻击意图不会在未决定先攻时自动扣血，进入敌对回合由 DM 明确开启战斗。

## 修复点

- 新增 battle.npcEnd（校验 actorId、turnKey、reason）、battle.advance（处理基础 NPC 直到玩家或待办）、battle.surprise（已裁定的突袭登记），以及对应 dm.action / dm-action 围栏兼容入口。
- 沿用 2014 规则：被突袭者首次回合不能行动或移动，在该回合结束后恢复反应；并非从先攻中删除。状态在回合结束解除，不在回合开始提前移除。规则依据：[2014 基础规则 Combat](https://www.dndbeyond.com/sources/dnd/basic-rules-2014/combat)。不会根据一句剧情自动猜哪些单位被突袭，DM 须用接口登记。
- DM 工具失败时以明确失败说明替换成功叙述；未收到回合推进回执却声称交给玩家时，显示真实当前行动者。仍不保证模型所有自由文本都无幻觉，实际状态、骰子与事件记录才是结算依据。
- 战斗页读取统一战斗日志，涵盖旧 DM 接口的伤害、状态、先攻和新执行器动作，避免两套日志脱节。
- 地精 A/B/C、数字后缀按基础名称匹配可靠怪物条目，补齐 AC/豁免/基础近战资料，保留已经损失的 HP；无法匹配的自定义怪物继续要求绑定来源。AI 的 enemy.bind 工具可在战斗中使用。
- 棋子下方展示简短名称，界面不展示内部编号；点击仍用唯一 ID 防止同名目标串位。

## 验证

40 项隔离回归通过，包含先攻队列门控、突袭到期、NPC 空过身份与版本校验、敌方基础回合循环、旧接口日志、带后缀地精 AC、自由潜行和模型假成功。31 个旧面板渲染检查通过。桌面实测自动切页、首轮突袭空过、玩家按钮亮起、第二轮返回玩家和自由潜行。

已有用户授权的 DeepSeek 配置在线隔离实测：实际调用 battle.surprise + battle.advance 完成突袭空过；玩家结束回合后第二轮自动返回玩家，AC=15，统一日志记录实际事件。测试不修改真实角色/战役，也不输出 API 密钥。

旧存档若突袭只存在于对话而没有状态，需让 DM 登记，或在确定该 NPC 应空过时使用人工入口。打开战斗页会尝试补齐旧地图上缺失的可靠怪物简表，不自动改动剧情结果或玩家 HP。

最终打包版验收通过：突袭空过、自动切页、第二轮返回玩家、统一日志、自由潜行、隐藏编号及原有卡片/拖动交互均成功，页面错误为 0。完整发布包为 source/dist/SoloTRPG-0.11.0-Windows-x64.zip，保留独立的 runtime 与 library 目录。
