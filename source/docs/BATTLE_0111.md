# 0.11.1 移动后敌方资料报错修复

- PDF 提取把命中和伤害拆成多段时，合并同一攻击的片段；兼容命中修正的前后写法，遇到下一个攻击或怪物资料边界停止，避免串用数据。
- 敌人绑定恢复攻击修正、伤害骰和触及距离；旧绑定在读取战斗状态时自动补全，保留受伤后的 HP。
- 地图设置、新增棋子和批量新增保留攻击字段；自由模式的敌方执行入口直接返回不执行状态，AI 工具列表按模式限制。
- 重复失败提示去重。资料确实缺失时仍暂停战斗，由 DM 查证，不虚构攻击数值。

验证：增加合成 PDF 分片格式与导入条目的隔离回归，涵盖绑定、地图替换、重启及多次自由移动。真实存档仅做只读定位，不用于写入测试。
