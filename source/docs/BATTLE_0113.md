# 0.11.3 倒地暂停与对话选项

全员倒地时停止自动敌方循环，显示等待裁定。重复调用和重启不重复写暂停日志；治疗或有效状态变化后可重新执行。玩家可请DM裁定，或明确确认敌方暂不行动，按先攻推进至玩家死亡豁免。不会自动宣告死亡、胜利，也不自动跳过敌方行动。其他敌方执行错误同样保持暂停，等待状态修正。

DM显式choices字符串数组显示为按钮；兼容带选择提示的A/B和数字选项。只有最新回复可点击，点击发送完整行动文本并防重复提交。始终显示自定义行动输入框，不限制玩家只能选预设方案。检定成功失败阈值不会变成选项。

验证：隔离测试覆盖暂停去重、重启、治疗恢复、稳定角色、死亡豁免及选项解析。桌面实际点击验证选项发送、防双击、自定义输入及倒地暂停后的死亡豁免交接。
